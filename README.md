# shadcn-drag-and-drop

A Next.js drag-and-drop demo showcasing sortable pills with variable widths using dnd-kit and shadcn/ui components.

**Demo:** https://shadcn-drag-and-drop.vercel.app/

## What is this?

This project demonstrates:
- Drag-and-drop functionality using `@dnd-kit/core` and `@dnd-kit/sortable`
- Visual drop position indicators
- Dynamic pill widths based on content
- Modern UI components from shadcn/ui
- Built with Next.js 15 and React 18

## Prerequisites

- Node.js 20 or higher
- npm (comes with Node.js)

## Getting Started

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for production

```bash
npm run build
npm run start
```

### Lint the code

```bash
npm run lint
```

## Tech Stack

- **Framework:** Next.js 15.1.11 with Turbopack
- **UI Library:** React 18.3.1
- **Drag & Drop:** @dnd-kit/core, @dnd-kit/sortable
- **Styling:** Tailwind CSS with shadcn/ui components
- **Language:** TypeScript
